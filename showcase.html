⚙️ Flow

How ChatSphere Works

From authentication to real-time delivery — follow the journey of a message.

🔐

Register / Login

User registers with username, email & password. bcrypt hashes the password. JWT token issued on login.

🔌

WebSocket Connect

Client connects to Socket.IO with JWT in handshake. Server verifies token before allowing connection.

💬

Join Chat Room

User selects a contact. Both join a unique room (sorted user IDs). Messages routed to that room only.

📨

Send & Receive

Message sent via REST → saved to MongoDB → emitted via Socket.IO → received in real time by recipient.

✅

Read Receipts

Messages marked read → DB updated → Socket emits read event → blue double ticks update for sender.

✨ Features

Everything You Need

A complete, production-grade feature set — from security to real-time presence.

⚡

Real-Time Messaging

Bi-directional WebSocket communication via Socket.IO. Messages arrive instantly without page refresh.

🔐

JWT Authentication

Stateless authentication with JSON Web Tokens. Passwords hashed with bcryptjs. Tokens expire for security.

🟢

Online Presence

Live online/offline indicators. Last seen timestamps. Users tracked with a socket map for multi-tab support.

✍️

Typing Indicators

Real-time typing notifications. typing and stop_typing socket events update the UI instantly.

✅

Read Receipts

Messages marked as read when the recipient opens the conversation. Unread counts auto-clear.

📁

File Uploads

Multer-powered file attachment support. Files stored in the uploads directory with size/type validation.

🛡️

Security Hardened

Helmet HTTP headers, CORS policies, express-rate-limit to prevent abuse, input validation with express-validator.

📊

Winston Logging

Structured production logging with Winston. Connection events, errors, and business events all logged.

📱

Responsive UI

Mobile-friendly React + Vite frontend. Sidebar collapses on mobile. Smooth transitions and animations.

📡 API

REST Endpoints

Clean, versioned REST routes for authentication, users, and messages.

Method Endpoint Description Auth
POST /api/auth/register Register new user with validation —
POST /api/auth/login Login and receive JWT token —
POST /api/auth/logout Logout and invalidate session 🔑 JWT
GET /api/users List all users (for sidebar) 🔑 JWT
GET /api/users/:id Get user profile by ID 🔑 JWT
PUT /api/users/profile Update avatar, username, bio 🔑 JWT
GET /api/messages/:roomId Fetch paginated message history 🔑 JWT
POST /api/messages/send Send a message (saves + emits socket) 🔑 JWT
🔌 WebSockets

Socket.IO Events

Real-time event-driven communication between client and server.

📤 Client → Server

join_room Client joins a chat room using sorted user IDs as room key.
typing Emitted while user is typing. Broadcasts to room participants.
stop_typing Emitted when user stops typing or sends message.
mark_read Marks all unread messages in a room as read. Updates DB + clears badge.

📥 Server → Client

newMessage Broadcasts new message to all room members in real time.
userOnline / userOffline Broadcasts presence changes to all connected clients with lastSeen.
user_typing / user_stopped_typing Delivered to room members to show/hide typing indicator UI.
messages_read Tells sender their messages were read. Triggers double-tick update.
conversationUpdated Syncs sidebar: updates unread count, last message, and timestamp.
